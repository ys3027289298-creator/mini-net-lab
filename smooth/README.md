# smooth

远端实体的预测平滑，解决延迟抖动导致的角色瞬移。`make test` 跑自检
（单元测试 + 确定性网络仿真，另有 2000 随机种子压力测试见下）。

## 三档机制

1. **按延迟分布调预测前置**：单向延迟样本进 32 格环形缓冲，取 p90 分位数
   作为渲染前置 `lead`（约 90% 的所需快照已到达），并钳制在
   `[LEAD_MIN, LEAD_MAX] = [0.05, 0.30]s`。
2. **按误差指数收敛**：权威目标与渲染位置的误差用一阶指数滤波收敛，
   时间常数 `tau = 0.08s`，增益 `k = 1 - exp(-dt/tau)`，单调不超调。
3. **超阈值才硬校正**：仅当快照在**插入时**被判定为不连续（实际位置与按
   速度推算的预期位置相差超过 `SNAP_DIST = 1.0`，即真实传送）才瞬时校正；
   标志锁存到校正完成，防止被后续平滑帧清掉。长尾延迟造成的外推漂移不是
   不连续，按同一增益向误差包络边缘平滑靠拢，**永不产生瞬移**。

## 关键设计点

- **不连续在插入时检测**，不是渲染插值时：传送前的快照可能在传送快照
  进入时已被环形缓冲逐出，二者从不同时存在于缓冲中，插值期检测会漏判。
- **硬校正与软钳制分离**：p90 前置天然有约 10% 概率让渲染点越过最新快照
  进入外推区。外推漂移走软钳制（单帧位移 ≤ `k·SNAP_DIST`），只有权威
  不连续才硬校正。
- **冷启动宽限**：前 `GRACE = 0.5s`（与延迟样本预热期对齐）不参与跳变
  统计，避免首个可渲染帧的初始化位移被误计。

## 延迟样本不足的处理

样本数 `< DD_MIN(8)` 时不信任分位数，前置回退到保守默认值
`LEAD_DEFAULT = 0.20s`，自检中以 `fallback` 帧数（`warmup_fallback_seen`）
显式覆盖此路径。样本达标后自动切换到 p90。

## 验证口径（仿真，固定随机种子可复现）

| 指标 | 保证 |
|---|---|
| 位移跳变（>3x 正常帧位移） | 平滑路径与零抖动基线均为 **0** |
| 硬校正 | 普通抖动 **0 次**；真实传送恰好 1 次 |
| 平滑滞后上界 | `LEAD_MAX + tau + SNAP_DIST/v + dt = 0.5633s`，实测最坏 0.372s |
| 单帧位移上界 | `v·dt + k·SNAP_DIST = 0.2881`，实测最坏 0.188 |
| 对照 | naive（直接贴目标）在 2000 种子上一致地更粗糙，证明抖动真实存在 |

2000 种子压力测试（独立驱动，不进主二进制）对以上全部指标零违反。
滞后为视觉位置相对真实位置的时间等效量，仅在单调运动段测量，传送时刻起
排除。
