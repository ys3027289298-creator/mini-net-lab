# guard

连续性校验反瞬移：按速度/加速度约束建可达域，超域判异常。

`make test` 跑自检。

## 模型

给定最近两个已接受上报 `(x0,t-2)`、`(x1,t-1)`，tick 间隔 `dt`，下一上报的可达域为两圆盘交集：

- 速度约束：`|x - x1| <= vmax*dt + k*sigma`
- 加速度约束：`|x - (2*x1 - x0)| <= 0.5*amax*dt^2 + k*sigma`

落在域外即异常。`sigma` 为上报噪声每轴标准差，`k` 为噪声余量倍数。

## 误报率上界

只假设噪声零均值、每轴标准差 `sigma`（分布无关）。对二维噪声平方范数用 Markov 不等式：

- 速度项误报 ≤ `4/k^2`，加速度项误报 ≤ `12/k^2`
- 单次观测 FPR ≤ `16/k^2`；同一玩家 N 次观测并集界 ≤ `16N/k^2`

## 标注集评估与阈值方向

自检内置人工标注作弊集（不同幅度瞬移，含贴近决策边界的小跳），输出混淆矩阵并要求漏报为零、经验 FPR 不超过理论界。调参窗口：

- 保零漏报：`k < min(作弊事件的 max(speed_z, accel_z))`
- 达目标误报率 `a`：`k >= sqrt(16/a)`

`verdict` 报告当前阈值状态：`too_loose`（有漏报 → `decrease_k` 收紧）、`too_tight`（误报超目标 → `increase_k` 放宽）、`in_range`。

丢包（tick 不连续）时轨迹重同步、不报警，避免丢包变成误封。
