# budget

不同同步率下，回滚代价差别很大。本模块给回滚加一层**预算**，在一条预生成
的事件流上对比「预算引擎」和「无限制回滚引擎」，并给出可验证的状态误差上界
与回滚深度直方图。

`make test` 跑自检（决策核心单测 + 仿真对比，全部 `=1` 才算过）。

## 代价模型

每个 tick 维护两个 EMA 估计量：

- `sync_ema`：同步率（仿真里在好窗口 0.90 / 坏窗口 0.55 之间时变）
- `err_ema`：最近校正的预测误差

一次深度为 `d` 的回滚代价：

```
cost(d) = d · (1 + err_scale · err_ema) / max(sync_ema, 0.05)
```

同步率越低、预测误差越大、回滚越深，代价越高。`budget_expected()` 再按
失配概率给出每个 ack 槽位的期望代价 `P(mismatch) · cost(期望深度)`。

## 预算与三级决策

预算是每帧 `refill`、容量 `cap` 的令牌桶，外加每帧硬深度上限 `max_depth`。
一次校正请求（深度 `d`）：

1. **全量回滚 `DEC_OK`**：`d ≤ max_depth` 且 `cost(d) ≤ tokens`，付全价，
   覆盖权威状态并重放后续 tick（精确校正）。
2. **降级插值 `DEC_INTERP`**：超预算或超深度，但付得起
   `INTERP_FRACTION · cost(d)`（默认 0.4）。当前状态按指数平滑
   `x += β(target − x)` 朝「全量重放本应到达的位置」靠拢（部分校正）。
3. **拒绝 `DEC_REJECT`**：令牌为零，或连插值那份代价都付不起。状态原样
   保留，校正被完全丢弃。

**预算为零时（`refill=cap=0`）任何请求都拒绝**，由 `zero_*` 单测与零预算
引擎共同保证。

## 误差上界（解析，逐 tick 断言）

令 `b = DRIFT = 2V` 为单 tick 状态差的最坏增长量。在线维护一个标量上界
`B`，每帧按实际决策更新：

| 事件 | 更新 |
|---|---|
| 普通预测帧 | `B += b`（一次预测漂移） |
| 全量回滚到深度 d | `B = b·d`（重放残差，每 tick ≤ b） |
| 插值（深度 d，系数 β） | `B = (1−β)B + β·b·d` |
| 拒绝 | 不变（已计入此前的漂移） |

每帧断言实际 `|引擎状态 − 权威真值| ≤ B`，违例计入 `bound_violations`，
测试要求其为 0。无限制引擎另有结构性上界 `b · 最大滞后`。

## 输出

- 深度直方图：分 `requested` 与 `rejected-or-degraded` 两列，桶为
  `0 / 1 / 2-3 / 4-7 / 8-15 / 16-31 / 32+`。
- 状态误差（×1000 单位）：无限制引擎峰值、预算引擎峰值与其解析上界峰值、
  零预算引擎峰值与其上界。
- 预算账本：`requests / rollbacks / interpolations / rejects`，并校验
  三者之和等于请求数、直方图计数与账本一致。

## 文件

- `src/budget.c`：决策核心（令牌桶 + 代价模型）、1-D 预测缓冲与重放/插值、
