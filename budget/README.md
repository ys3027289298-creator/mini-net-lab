# budget

按距离与视野权重分配实体更新频率，替代按同屏人数均分。`make test` 跑自检。

## 两个函数

| 函数 | 含义 | 方向 |
|---|---|---|
| `bw_of(f) = PKT * f` | 单个实体每秒更新的字节数 | 随 f 上升 |
| `err_drag(f)` | 视野内：接收端按快照速度外推时的位置 RMS | 随 f 下降 |
| `err_hold(f)` | 视野外：接收端冻结最后一帧时的位置 RMS | 随 f 下降，慢得多 |

两条误差曲线来自同一个模型（航向为积分 OU 过程），分别是外推与冻结对快照
年龄的两种平均。绝对数值由 `budget cal` 用常数频率仿真校准，\~40 Hz 以内
与仿真相差 ±4%。

## 分配

```
f_i = beta * B / PKT * w_i / sum(n_j * w_j)
w(d) = 1/(1 + d/D0)   d <= R_VIS
w(d) = W_OUT          d >  R_VIS
```

`beta` 是预算使用比例，频率封顶在服务器 tick 60 Hz。三个候选分配点
β = 0.55 / 0.70 / 0.85，选中 0.70。默认 10 KB/s、每次更新 40 B、
AOI 半径 25 m、D0 = 15 m、W_OUT = 0.15。

## 命令

| 命令 | 输出 |
|---|---|
| `./budget` | 自检（模型、分配、仿真分支） |
| `./budget curves` | `out/curves.csv`：f、带宽、两条误差曲线 |
| `./budget cal` | `out/cal.csv`：常数频率校准点 |
| `./budget exp` | `out/exp.csv`：3 个分配点 × 3 档人数 × 3 类位置 |
| `./budget equal` | `out/equal.csv`：同预算均分基线 |
| `python3 tools/build_report.py` | 用 `out/*.csv` 生成 `report.html` |

`report.html` 是自包含的（数据和脚本都内嵌），直接打开即可。

## 结论

选中点 β=0.70、密集档（48 人）下贴身 7.7 Hz / 4.4 cm、视野内远 4.4 Hz /
9.8 cm、视野外 1.5 Hz / 2.55 m。同预算均分是全部 3.7 Hz：贴身 12.8 cm、
视野内远 12.4 cm、视野外 1.13 m。

曲线预测与实际在贴身、视野内远两类上差 1%；视野外实际值比外推预测高
3.4–12.7 倍，与冻结预测差 ≤2%。漏掉的耦合项是视野外的接收行为：不渲染、
不预测，误差是整段滞后时间内的位移（`V·age`），而不是外推残差。
