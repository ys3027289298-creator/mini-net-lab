# mini-net-lab

游戏网络同步基础模块，C 实现，每目录独立构建可自测。

| 目录 | 内容 |
|---|---|
| `snapshot/` | 状态快照量化编解码、变长 tick |
| `clock/` | 时钟偏移估计、最小 RTT 过滤、样本环 |
| `aoi/` | 网格兴趣区域、半径查询、进出差集 |
| `reconcile/` | 预测缓冲、权威校正、回滚计数 |
| `timebase/` | 共享单调时间基准、时间源校验、漂移统计 |

## 统一时间基准

四个模块原先各自打时间戳，长时间运行会互相漂移。现在它们都通过
`timebase/` 推进时间：

- **单位**：整毫秒，`uint32_t`，上限 `TIME_MAX_TICK`（2^31-1 ms ≈ 24.8 天）。
- **单调**：基准只前进。模块自己的 tick 回退会被拒（`backward`）；落后于
  共享基准但未低于自身上次值，记为 `lagging`（滞后不算错）。
- **非法时间源**：源为空、读数回退、超范围都返回错误，并按模块计入
  `rejects`，错误定位到具体模块（`snapshot` / `clock` / `aoi` / `reconcile`）。
- **不使用系统时钟**：全部由注入的 `tb_read_fn` 驱动，验收结果与机器、
  时区、墙上时间无关。

## 验收

```sh
./tests/run.sh          # 构建 + 自检 + golden + 验收 + 漂移报告 + 确定性
```

- `make -C <module> test`：模块自检，输出与改造前逐字节一致。
- `make -C <module> accept`：该模块的验收（正常 / 长时间 / 非法源）。
- `tests/golden/*.out`：改造前保存的成功路径输出，用于逐字节比对。
- `tests/drift-report.sh`：四模块漂移数据汇总 + 共享时间基准一致性。
- `tests/determinism.sh`：确认无系统时钟调用、复跑字节一致、时区无关。
