# resample

变帧率重采样：快照按服务端 tick 存，渲染按本机时刻（时钟偏移对齐后）采样。

- `resample_push` 保序、限容（64 条）地存快照；`resample_sample` 按渲染时刻定位区间，用含速度的三次 Hermite 求值。
- 渲染时刻落在区间 `[t0, t1]` 内用区间参数 `u` 求值；落在时间轴两端之外时，沿端点区间的另一侧做线性外推（端点无速度则保持端点值，置 `RESAMPLE_F_HOLD`），越界超过端点区间长度的 `RESAMPLE_EXTRAP_LIMIT`（0.25）即拒绝采样（`RESAMPLE_ERR_FAR`）。
- 区间某一端缺速度时，该端的 Hermite 切线取割线（等于该侧线性），结果置 `RESAMPLE_F_LINEAR`；两端都缺就是纯线性。
- 时间轴不单调（乱序、重复 tick、换帧率后时间倒流）的快照拒绝写入；单帧间隔超过 1 s 也拒绝，避免用错误的帧率解释时间轴。

`make test` 跑自检，`all_ok=1` 即全过；误差实测值与上界一起打印。

## 误差上界（`resample_error_bounds`）

由已存快照的滚动最大值导出（`H = max dt`、`D = max |v|`），保守常数：

- 位置插值误差：`|err| <= H*D/2`。常速下 Hermite 精确；线性退化的曲率误差量级 `H^2*accel/8`，常规运动下仍被该界覆盖。
- 角度误差：把 `v` 换成角速度即 `|err| <= H*omega/2`。按 `|v|` 上界估计、不做圆周包裹，因此对每秒 ≥1 圈的角度同样成立（插值运行在非包裹的线性数域）。
- 位置超调：Hermite 曲线偏离同一区间两端点连线（弦）的距离不超过 `(4/27) * max(|r0| + |r1|)`，其中 `r = dt*v - chord`（缺速度的一端 `r = 0`）。差值函数是 `u(1-u)((1-u)r0 - u·r1)`，每个基函数权重绝对值不超过 `4/27`，故这是稳妥上界而非常数最优；单端缺速时曲线贴在弦与端点切线之间，不越出端点坐标范围。

这些上界取的是自初始化以来所有区间（含已被容量淘汰/`resample_prune` 清掉的区间）的最大值，只增不减。

自带测试用解析轨迹 `p = (3cos(0.5t), 1.5sin(0.8t))`、`theta = 0.7t + 0.3sin(t)`，按 40/52/24/75 Hz 变帧率采样（快照 40 Hz）：位置/角度误差实测约 `2e-7` 和 `8e-8`，均远小于上界；每次帧率突变处额外检查相邻帧位移不超过 `vmax * 帧间隔`，即没有跳变。
