# predict

自适应预测器：在滑动窗口上对允许模型集（CV 常速 / CA 常加速 / CJ 含加加速度）做最小二乘拟合，按 AIC（曲率失配 vs 噪声下的参数罚）加滞回选模型；切换时 cross-fade 混合旧新模型输出，保证不跳。

每次预测给出置信区间（兼作误差上界，`pred_error_bound`）；观测落到区间外即报告（`misses` 计数、`degraded` 标志）并降级：σ 膨胀、强制退回最简模型，覆盖率恢复后自动解除。模型集为空（mask=0）时 `pred_init` 拒绝。

自检内含常速卡尔曼滤波基线与直线外推基线：直线段自适应误差与 KF 相当，转弯段显著优于两者。

`make test` 跑自检。
