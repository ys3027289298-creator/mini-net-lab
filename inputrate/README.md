# inputrate

按窗口统计输入间隔，用分布拟合检测客户端发包频率异常。`make test` 跑自检。

## 做什么

每个玩家一条数据流，按固定时长切窗，窗内取包间隔。对每个窗口做两个互补的
单侧检验（判据都是“比基线发得更快”）：

| 检验 | 统计量 | 抓什么 |
|---|---|---|
| 位置 `z_loc` | 窗均值相对基线均值的正态分数，标准误含基线均值本身的拟合不确定度 | 整体提速（如改包频 ×2） |
| 短间隔质量 `p_short` | 低于 `mu - short_z*sigma` 的间隔数的精确二项上尾 | 在基础节奏上叠加额外短包 |

两者取较小 p，乘 Bonferroni 因子 2，得到窗级 p 值；`p < alpha` 才判异常。

基线由热身期的截尾正态拟合（迭代剔除 3σ 外样本）给出：`mu`、`sigma`、`n_fit`。

## 策略

- **异常判定**需要窗口样本数 ≥ `min_samples`，且 `p < alpha`。
- **样本不足** → `IR_INSUFFICIENT`，附带 `p_value` 与 `confidence = 1 - p`，不判定、不封禁。
- **非法阈值/非法数据** → `IR_EINVAL`，`ir_session_init` 失败时状态一个字节都不改。
- 本模块**没有封禁函数**：升级处置由人决定，模块只产出可审计的判据。

## 误报量化：`ir_calibrate`

在人工标注集（`is_anomaly` 字段）上选阈值：

1. 收集所有**可判定**异常的最大 p 值，取 `alpha = nextafter(max_p, 1)`；
   `p < alpha` 对 alpha 单调，所以这是满足零漏报的阈值里误报最少的那个。
2. 用该阈值跑干净窗，统计 `fp`，给 **Hoeffding 单侧上界**，
   置信度 `1 - delta`，不依赖任何分布假设。
3. `feasible = (fn == 0 && fp_rate_ucb <= ceiling)`。

不可行时返回 `feasible = 0` 但仍是成功调用——这是有效结论，不是异常。
若标注异常里有样本不足而**无法判定**的（`undecided_anom > 0`），
同样判不可行：静默漏报也是漏报。

## 自检覆盖

`make test` 用固定种子的合成数据（正常节奏 + 偶发真实停顿；2×、1.5×、1.2× 提速；
注入短包）+ 人工标注比对，输出可读的计数与上界：

- 正常窗 200 个，异常窗 90 个：`fn == 0`，检测率逐类 30/30。
- 1.2× 边缘作弊：标定自动抬高 alpha 至 ~3e-7，仍零漏报；
  同阈值用于干净集的误报代价被**实测**出来，并给出上界。
- 样本不足的窗口：输出置信度而非判决；整条流不会产生任何封禁信号。
- 各类非法阈值（窗长 0/NaN/Inf、alpha 0/过大、min_samples 越界、short_z 越界、
  warmup 0、ceiling/delta 越界）全部拒绝且状态不变。

注意：`fp_rate_ucb` 依赖干净窗数量，200 个时才压到 ~8.7%；
要报更紧的上界必须提供更多标注干净窗，这是样本量的硬约束，不是调参能绕过的。
