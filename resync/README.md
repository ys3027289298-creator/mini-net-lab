# resync

重连后的物品状态补发：回放断线期间的物品更新日志；断线太长，增量反而
比全量快照更贵时，改发全量。

- `make test` 跑自检，并打印 1s / 30s / 180s 三档断线的补发字节数与恢复耗时。
- 上限由 `全量快照字节 / 增量字节率` 反解，增量字节率来自物品更新频率与
  单条更新记录的实际编码长度。
- 恢复耗时 = 补发字节 / 大厅下行带宽 + 本地应用耗时（不含重连握手的固定 RTT）。

仿真参数：1024 件物品，每秒 128 条物品更新（0.125 次/件/秒），全量记录
64 B/件，大厅下行 64 KiB/s，日志保留 300 s。
