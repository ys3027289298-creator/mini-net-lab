# aoi_tier

高速玩家提级与兴趣区域裁减放宽。

## 规则

- 每个 tick 按实际位移测速，速度（单位/tick）严格大于 `SPEED_THRESHOLD` 的玩家提级为高速档；
  等于阈值不提级。
- 普通玩家按基础半径 `R_BASE` 裁减；高速玩家裁减半径放宽一档
  （`R_FAST = R_BASE + RELAX_STEP`），高速状态结束后自动恢复普通档，其他玩家不受影响。
- 观察者固定在原点，实体沿 x 轴在 `[-MAP_BOUND, MAP_BOUND]` 内反弹。

## 自检（`make test`）

三种速度轨迹各跑一次（每组 2 个玩家、80 tick）：

| 组 | 速度（单位/tick，含抖动） |
|---|---|
| walk 步行 | 1.8 ~ 2.2 |
| run 奔跑 | 4.5 ~ 5.5 |
| vehicle 载具 | 10.8 ~ 13.2 |

阈值 8.0，三组速度与阈值之间均有明确间隔。逐玩家输出快照覆盖率、
普通规则与放宽规则下分别被裁掉的帧数、放宽规则救回的边界帧；三组分别汇总。
低速组（walk/run）若有任何一帧被误提级，会输出误判帧号列表并使自检失败。
