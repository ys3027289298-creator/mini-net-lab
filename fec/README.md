# fec

块级前向纠错：系统 RS 编码（GF(256)，Cauchy 生成矩阵）与冗余规划。`make test` 跑自检。

- **编码**：每块 `k` 个数据包 + `m` 个校验包，任意 `k` 个存活包即可重建整块，块内最多修复 `m` 个丢失。
- **选冗余率**：`fec_plan` 按实测丢包率选能使恢复概率达到目标的最小 `m`，输出额外带宽（`m/k`）。
- **恢复概率上界**：`fec_recover_prob_ub` 按独立丢包、MDS 假设给出精确值，即实际上界；突发/相关丢包会使真实恢复概率更低（见下方说明）。
- **时延对比**：`fec_compare_latency` 与重传方案（`rtt/(1-loss)`）比较平均恢复时延。
- **拒绝**：`m == 0` 的编码/规划一律返回 `FEC_ERR_ZERO_REDUNDANCY`；规划在丢包率为 0 或能力上限内冗余率为 0 时同样拒绝，而不是静默关闭保护。
- **冗余率过高**：所需 `m` 超过 `max_overhead` 时仍返回 `FEC_OK`，但置 `over_cap = 1`，并保留 `required_m` 供上层报告/告警。
