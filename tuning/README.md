# tuning

更新频率调参：扫频率 → 带宽/误差，画 Pareto 前沿，定位拐点并与穷举最优比对。

- `make test` 跑自检（含零频率拒绝、样本点不足、偏差上界校验）。
- `make sweep` 输出 `tuning_sweep.csv` 与 `tuning_frontier.svg`，并打印拐点、选择依据、与穷举最优的偏差及上界。

模型：带宽 = 频率 × (snapshot 编码包长 + UDP 头）；误差 = 量化下限 + ½·a/f²（死推漂移）。拐点取归一化平面上距端点弦最远的点；粗扫拐点与稠密网格（穷举）拐点的偏差上界为粗网格的一个 log 步长。样本点 < 3 时拐点无定义，拒绝并说明。
