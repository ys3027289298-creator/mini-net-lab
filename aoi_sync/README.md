# aoi_sync

AOI 与快照联动：可见集直接决定每 tick 的快照内容。

- 进入可见集 → 全量记录（REC_FULL）
- 已在集内、量化字段有变化 → 带字段掩码的增量记录（REC_DELTA）
- 离开可见集（含 despawn）→ 恰好一条收尾记录（REC_LEAVE），随后服务端遗忘该实体
- 重进入 → 客户端已无基线，重新发全量记录补全
- 可见集为空 → 置 anomaly 并计数，只发必要的收尾记录，不退化成全量同步

不变量（自检逐 tick 断言）：AOI 客户端实体集 == 当前可见集（离开后残留为零），
且每个实体与全量同步参考客户端逐字段一致。

`make test` 跑自检。
