# inqueue

客户端预测输入重排队列，`make test` 跑自检。

- 序号为 `uint32`，在 `2^32` 处自然回绕；比较走有符号循环距离 `(int)(a - b)`，回绕两侧的新旧关系与窗口判断均正确。
- 窗口 `window` 可配（`1..64`）：仅接受相对 `next` 偏移落在 `[0, window)` 的输入；槽位按相对偏移 `(head + 偏移) % window` 索引（不直接用原始序号取模，否则 `2^32` 回绕处会撞槽误判重复），入队 O(1)。
- `iq_push` 返回 `0` 已缓存、`-1` 过期/重复（计 `dupes`）、`-2` 超出窗口（计 `dropped`）；窗口为零、负值或超限由 `iq_init` 拒绝。
- `iq_pop` 按序吐出输入，遇到未补齐的缺口返回 `0` 阻塞回放，模拟因此暂停而不是乱序推进。
- 自检含乱序到达（块内反转、位移小于窗口）与回绕两组场景，分别与按序参考模拟逐字段比对状态。
