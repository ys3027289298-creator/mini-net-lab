# scenetree

场景树增量重建：改动标记（dirty mark）沿父链传播到根，重建只进入脏子树，干净子树直接复用缓存校验和（标记命中）。

传播规则（保证不漏）：

1. 所有状态修改必须走 `set_pos` / `set_hp`，不允许裸写字段；
2. `mark_dirty(n)` 标记 n 并沿父链标记到根（遇到已脏祖先可停，其祖先早已标记）；
3. 子节点构建时依赖父节点世界变换，因此移动一个节点要把整棵子树标脏（向下标记依赖者）。

`make test` 跑自检：含 300 帧随机变更下增量结果与全量重算逐帧比对（不漏校验）。
`make bench` 跑基准：10 / 50 / 200 人，各 3600 帧（60s @ 60fps），每帧记录重建节点数与主线程耗时，并输出标记命中率 `hit_ratio` 与全量重建基线 `full_rebuild_us` 作对照。`checksum_match=1` 表示该规模下每一帧增量结果都与全量一致。
