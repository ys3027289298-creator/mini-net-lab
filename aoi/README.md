# aoi

`make test` 跑自检。

网格兴趣区域，含半径查询、进出差集，以及按密度自适应分块的四叉树索引。

## 固定网格与自适应分块

固定网格全图使用同一个单元尺寸：城门口人挤爆，野外空着也照样占一格。
自适应分块在固定网格之外再维护一棵四叉树：

- 叶子实体数超过 `SPLIT_ENT` 就继续四分，密集区自动变成小格，稀疏区保持大格；
- `world_add/move/remove` 只置脏位，下一次查询（或显式 `world_rebuild`）重建索引，
  把所有存活实体重新装进对应叶子；id、坐标、未取走的进出事件都不动；
- 查询仍做精确半径判断，所以自适应可见集与固定网格**完全一致**，自检里用固定网格
  与暴力扫描两条参考实现做随机比对；
- 存活实体少于 `MIN_SAMPLES` 时密度样本不足：不做按密度缩放，叶子保持原 `base_cell`
  尺寸，`RebuildInfo` 返回 `sample_ok=0`、`cell_kept=1`；
- `world_step` 先补建索引再算可见集，迁移不产生假事件。

## 自检输出的单次查询耗时

`make test` 最后按区域分档打印单次查询耗时（纳秒分桶），并给出每查询的索引工作量：

```
zone=dense iters=20000
  query_adaptive_ns: <50=.. <100=.. <200=.. <400=.. <800=.. <1600=.. >=1600=.. avg=..
  query_fixed_ns:    ...
  work_per_query: adaptive_nodes=.. adaptive_tests=.. fixed_cells=.. fixed_tests=..
  identical=1 mismatch=0
```

`dense` 是城门口 24×24 范围内的高密度区域，`sparse` 是野外稀疏区域。
自适应分块在密集区削减了大量精确距离判断，稀疏区则因多一层节点遍历略慢；
两个区域都同时校验可见集与固定网格逐项一致。
