# replay

序号回绕下的重放与重排窗口。

- `seq_newer`：半区间比较，`(a-b) mod 2^32` 落在 `(0, 2^31)` 才算更新；相等与正对点（恰好相差 `2^31`）无序。
- `window_contains` / `window_newer`：重排窗口为 head 之前 `WIN`（64）个序号；因 `2*WIN < 2^31`，窗口内偏序是全序，且与真实（不回绕）顺序逐对一致，窗口外不可比。
- `Stamp` / `window_newer_stamped`：调用方若持有会话真实 tick 高度，可用 `truth` 打破裸比较的平局（两个 epoch 发出相同线上序号时），窗口序仍是严格全序。
- `Replay`：乱序提交按窗口偏序插入；`replay_fold` 按真实顺序折叠。破坏偏序时 `report_conflict` 打印 `conflict=1 older=<序号> newer=<序号>`，并在 `conflict_older` / `conflict_newer` 中保留这对序号；正对点无 older/newer 之分，打印 `conflict=1 ambiguous=1 a=<序号> b=<序号>`。

测试覆盖：

- 半区间边界：相等、±1、`2^31-1`、`2^31`、`2^31+1`、`0xffffffff`。
- 窗口边界（`head-WIN+1` 收、`head-WIN` 丢且不算冲突）与偏序三条公理（自反不可、反对称、传递、窗口内全序）。
- 窗口序与真实序逐对一致：多组起点，含 `0xffffffc0`..`0xffffffff` 等跨 0 位置；窗口平移不变性。
- 回绕点前后连续性：跨 0 的步长为 1、窗口跨 0 仍全序、回绕点乱序重放连续无空洞。
- 与不回绕序列结果一致：同一逻辑日志分别用 `1000+` 和 `0xfffffff0+` 编号乱序提交，折叠输出逐步相同。
- 冲突上报：折叠后迟到的旧序号、缓存被篡改、跨回绕的迟到序号、以及 `2^31` 正对点，均检查报告的两个序号。

`make test` 跑自检。
