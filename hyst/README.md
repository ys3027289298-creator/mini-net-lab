# hyst

按移动速度与 AOI 半径选滞回带宽，自检 `make test`。

## 要解决的问题

实体贴着 AOI 边界悬停时，可见集合每次都随穿越翻转，进出事件与相关状态更新会持续抖动。
滞回带宽 `h`：进判据为距边界内侧 `h/2`，出判据为外侧 `h/2`。带宽越大抖动越少、可见延迟越高，
推荐值取这条权衡曲线的拐点。

## 模型与证据

设采样周期 `dt`、边界相对位移的扩散系数 `D`。悬停期按扩散近似：

```
churn(h)   = kappa * D / (R * h)       每秒进出抖动次数
latency(h) = h / (2 v) + dt / 2        额外可见延迟
```

`D = kappa * v^2 * dt / 2` 由一维布朗悬停蒙特卡洛标定：`kappa = 1` 时，
在 `v ∈ [4, 16] u/s`、`h <= R` 范围内，实测 churn 与模型的比值落在 0.6–1.3；
`v = 2 u/s` 且 `h > 3` 时实测 churn 比 `1/h` 掉得更快（0.25–0.8 倍），
即模型在该段偏保守（高估抖动）。纵向延迟两段都吻合（误差 < 2%）。

关键一点：`kappa` 在归一化 `w` 中整体约掉，**拐点对 churn 标定严格不变**
（自检 `knee_kappa_invariant` 以 `kappa = 1` 与 `5` 验证）。因此拐点只由曲线形状
`latency ∝ h`、`churn ∝ 1/h` 决定；上面标定只影响 churn 的绝对读数，不影响推荐带宽。

纵向延迟对 `h` 仿射，横向 churn 与 `1/h` 成正比，归一化后
`g(h) = 1 - u(h) - w(h)` 在整个可行域上严格凹，极大值就是几何平均：

```
h* = sqrt(hmin * hmax) = sqrt(2 R v dt)
```

可行域 `[hmin, hmax] = [v*dt, 2R]`：小于 `v*dt` 采样分辨不了，大于 `2R` 带宽装不进 AOI。
`dt` 就是可见性采样周期。半径 `R` 指进入判据的内侧边界（AOI 半径），不是网格单元尺寸。

### 对延迟模型的敏感性

几何平均拐点来自“延迟对 h 仿射”这一条：多等半个带宽的位移，再加固定的半个采样周期。
若改成另一种可信模型——漏检要等到对侧翻转，延迟按真实驻留分布的尾部算，即 `latency ∝ h^2`——
拐点变为 `(hmin hmax (hmax+hmin)/2)^(1/3)`，默认参数下从 `2.587` 抬到 `5.116`。
延迟的**整体倍率**不影响拐点（归一化后约掉），只有 h 的**幂次**影响。
自检按仿射形式断言；换模型需要改 `hyst_latency` 并重跑 `bf_bound_holds_*`。

## 拐点偏差上界

穷举是同一模型在 `[hmin, hmax]` 上等距取 `n+1` 点的网格扫描（`hyst_bruteforce`）。
对凹函数，网格最优点到真实拐点的距离满足

```
|h_bf - h*| <= sqrt(2 (g* - g_bf) / m),   m = min |g''| = 2K / hmax^3,  K = hmin hmax / (hmax - hmin)
```

这个界是事后可算、当场可验的；同时恒有 `|h_bf - h*| <= step`（网格间距）。
自检对 6 组参数分别在 `n = 64` 与 `n = 4096` 下扫描，逐一断言实测偏差不超过上述界，
并检查细网格偏差不劣于粗网格。默认参数 `v=5, R=20, dt=1/30` 下，`h* = 2.5820`，
`n=4096` 的扫描偏差约 `3.5e-3`，而界约 `9.7e-3`（约 `2.7x` 余量）。

## 明确拒绝的情况

- **带宽为零**：`hyst_point(h=0)` 返回 `HYST_ERR_ZERO_BAND`，不给出 `churn = inf`。
  零宽带宽等于没有滞回，churn 无有限值，权衡曲线不存在。
- **缺少速度估计**：`hyst_init_from_speed` 返回 `HYST_ERR_MISSING`；
  `speed_est_why_missing()` 说明依据——滑动窗口内需要至少 4 个时间戳严格递增的速度样本，
  只有锚点或时间戳不递增的样本会被丢弃而不是除以零。
- 非正或 NaN 的速度、半径、`dt` 返回 `HYST_ERR_BAD_ARG`；
  `v*dt >= 2R`（采样步长已超过 AOI 直径）返回 `HYST_ERR_RANGE`。

## 速度估计缺失的依据

`speed_est_add` 只在时间戳严格递增时产出一个速度样本，窗口 8 个、至少 4 个才出值，
所以从零开始的前 4 个样本之内 `speed_est_v` 返回 -1。输出 RMS 速度及其标准误
（把窗口内 `v^2` 当独立样本：`se(v) = sqrt(var(v^2)/n) / (2v)`）。
标准误只反映采样离散，不含轨迹的真实加速度项；要更稳的估计应扩大窗口或先做平滑。
