# lockstep

确定性帧同步（lockstep）：确认帧推进 + 输入延迟窗口缓冲 + 缺输入预测标记 +
迟到回滚重放。`make test` 跑自检。

## 机制

- `ls_local(ls, p, sample_frame, in)`：本地输入按延迟窗口 `W` 调度到
  `sample_frame + W`，给网络传输留出 `W` 帧缓冲。
- `ls_store(...)`：远程输入入环形缓冲（按帧索引）。已确认帧的输入拒绝
  （`-1`），早于历史环的输入拒绝（`-2`），重复输入拒绝（`-1`）。
- `ls_tick(...)`：推进一帧。
  - 严格模式（`allow_predict=0`）：任一玩家缺输入即返回 `LS_STALL`，
    不推进，累计 `stall_frames`。
  - 预测模式：缺输入用上一条真实输入预测（无历史则中性输入），并在该帧
    `pred` 掩码和 `TickInfo.pred_mask` 上标记；帧照常推进。
- 迟到的真实输入覆盖预测并触发回滚：从该帧保存的世界状态重放到当前帧，
    累计 `rollbacks`，`max_backlog` 记录最深的重放深度。
- 预测帧的积压（`frame - confirmed`）超过窗口 `W` 时只累计 `overruns`
  并在 `TickInfo.backlog` 报告深度，不硬等。
- 模拟本身只用整数运算，保证逐字段确定性；每帧带 FNV 校验和。

## 自检场景

1. 单元机制：窗口调度、重复/陈旧拒绝、严格停顿、预测标记、迟到回滚、
   历史环保护。
2. 理想世界（无丢包无延迟）：100 帧全部真实输入推进。
3. 同一份确定性输入脚本跑损失网络（延迟 0~14 帧、含超出窗口的深度迟到）：
   - 预测模式：从不停顿，迟到输入回滚后与理想世界逐字段一致
     （x/y/vx/vy/帧号/校验和），输出预测帧数、回滚次数、最大积压、
     窗口超限次数。
   - 严格模式：同样网络下只停顿不预测，追平后状态同样逐字段一致，
     输出停顿帧数等指标。
