# interest

相关性裁剪（relevance culling）与全量广播的同场对比仿真，单文件 C，`make test` 自测。

## 裁剪策略

1. **兴趣区域 + 可见性**：AOI 半径 30 内才候选；视线线段与障碍物圆
   （点-线段距离 < 半径）相交则剔除。可见集每 tick 与上一 tick 做
   进出差集，enter 触发立即同步，leave 销毁客户端镜像并各记 2 字节事件。
2. **更新频率分级**：
   | 分级 | 条件 | 间隔 |
   |---|---|---|
   | near | 房间内且距离 ≤ 15 | 每 tick |
   | mid | 房间内、15 < 距离 ≤ 30 | 每 2 tick |
   | oob | 越出房间边界 `[0,100]^2` | 每 4 tick |
3. **空区域报告**：可见集为空的玩家逐 tick 计数，输出 id、空 tick 数、
   首次/末次空 tick。

## 线上字节模型（两条管线相同，保证对比公平）

单条更新 = 1 字节 id + varint tick + 两个 zigzag varint 量化坐标
（scale=32，与 `snapshot/` 同款编码），每个非空批次另加 2 字节包头。
全量广播基线路由全部其他玩家、每 tick 一条。

## 位置误差上界

裁剪端持有上次发送的量化位置，全量端持有当前 tick 的量化位置：

- 漂移：最长 4 tick 不发，`E_drift = VMAX * DT * 4 = 6 * 0.05 * 4 = 1.20`
- 量化：两端各自量化一次，每轴误差 ≤ 1/(2·32)，
  `E_q = 2 * sqrt(2)/(2*32) ≈ 0.0442`
- **上界 `E = 1.2442`**，仿真逐 tick 实测最大误差并断言不越界。

## 场景

36 个玩家、240 tick（20 Hz 下 12 秒）：1 个脚本化越界行走者、1 个门口
固定观察者、2 个房间外永久隔离的观察者、32 个中心区域随机游走人群，
3 个圆形障碍物。LCG 固定种子，结果可复现。
